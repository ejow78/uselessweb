Linked Lists

A linear collection of data elements whose order is not given by their physical placement in memory. Instead, each element points to the next.

Access: O(n) Search: O(n) Insert/Delete: O(1)*
Ready to start.

// Node Structure
class Node {
    constructor(value) {
        this.value = value;
        this.next = null;
    }
}

// Insert at Head (Prepend): O(1)
function prepend(value) {
    const newNode = new Node(value);
    newNode.next = head;
    head = newNode;
}

// Search: O(n)
function search(target) {
    let current = head;
    while (current) {
        if (current.value === target) return true;
        current = current.next;
    }
    return false;
}

// Delete Value: O(n)
function deleteValue(target) {
    if (!head) return;
    if (head.value === target) {
        head = head.next;
        return;
    }
    let current = head;
    while (current.next) {
        if (current.next.value === target) {
            current.next = current.next.next;
            return;
        }
        current = current.next;
    }
}

How it Works

A Linked List consists of nodes where each node contains a data field and a reference (link) to the next node in the list.

Unlike Arrays, Linked Lists elements are not stored at contiguous memory locations. This allows for dynamic memory allocation and efficient insertion/deletion (no shifting needed), but makes access slower because you have to traverse from the head.

Advantages

Dynamic Size
Can grow and shrink at runtime.

Efficient Insert/Delete
No shifting of elements required.

Disadvantages

Slow Access
Must traverse from head (O(n)).

Extra Memory
Requires extra memory for pointers.
