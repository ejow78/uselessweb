Hash Tables

A data structure that implements an associative array abstract data type, a structure that can map keys to values. It uses a hash function to compute an index.

Search: O(1)* Insert: O(1)* Delete: O(1)*

* Average case. Worst case O(n) with many collisions.

Ready to start.

class HashTable {
    constructor(size = 7) {
        this.buckets = new Array(size);
        this.size = size;
    }

    hash(key) {
        let total = 0;
        for (let i = 0; i < key.length; i++) {
            total += key.charCodeAt(i);
        }
        return total % this.size;
    }

    insert(key, value) {
        const index = this.hash(key);
        if (!this.buckets[index]) {
            this.buckets[index] = [];
        }
        this.buckets[index].push({ key, value });
    }

    get(key) {
        const index = this.hash(key);
        if (!this.buckets[index]) return null;
        for (let item of this.buckets[index]) {
            if (item.key === key) return item.value;
        }
        return null;
    }
}

How it Works

A Hash Table uses a Hash Function to convert a key (like "apple") into an index (like 3) where the value is stored.

Collisions: Sometimes different keys hash to the same index. We handle this using Chaining (storing a list at that index) or Open Addressing. This visualization uses Chaining.

Advantages

Fast Access
O(1) average time for lookup.

Flexible Keys
Can use strings, objects, etc. as keys.

Disadvantages

Collisions
Can degrade performance to O(n).

Unordered
Data is not stored in any specific order.
