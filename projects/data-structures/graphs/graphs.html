Graphs

A non-linear data structure consisting of nodes (vertices) and edges. Graphs are used to represent networks.

// Depth-First Search (DFS)
function dfs(node, visited = new Set()) {

            dfs(neighbor, visited);
        }
    }
}

How it Works

A Graph is a collection of nodes connected by edges.

BFS (Breadth-First Search) explores neighbor nodes first, before moving to the next level neighbors. It uses a Queue.

DFS (Depth-First Search) explores as far as possible along each branch before backtracking. It uses a Stack (or recursion).

Advantages

Modeling
Great for modeling real-world networks.

Pathfinding
Algorithms like BFS can find shortest paths.

Disadvantages

Complexity
Algorithms can be complex to implement.

Storage
Can consume lots of memory (Adjacency Matrix).
