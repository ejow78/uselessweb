Arrays

A collection of elements stored at contiguous memory locations. It allows random access to elements using indices.

Access: O(1) Search: O(n) Insert/Delete: O(n)

How it Works

An Array is the simplest data structure. It stores elements in a continuous block of memory. Because of this, the computer can calculate the exact memory address of any element if it knows the index, making Access extremely fast (O(1)).

However, Insertion and Deletion can be slow (O(n)) because if you add or remove an element in the middle, you have to shift all the subsequent elements to keep the memory continuous.

Advantages

Fast Access
Instant access to any element via index.

Space Efficient
Minimal overhead per element.

Disadvantages

Fixed Size
Usually needs resizing if full (in static arrays).

Slow Insert/Delete
Requires shifting elements.
