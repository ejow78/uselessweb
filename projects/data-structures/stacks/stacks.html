Stacks

A linear data structure which follows a particular order in which the operations are performed. The order is LIFO (Last In First Out).

Push: O(1) Pop: O(1) Peek: O(1)
Ready to start.

class Stack {
    constructor() {
        this.items = [];
    }

    // Push: O(1)
    push(element) {
        this.items.push(element);
    }

    // Pop: O(1)
    pop() {
        if (this.isEmpty()) return "Underflow";
        return this.items.pop();
    }

    // Peek: O(1)
    peek() {
        if (this.isEmpty()) return "No elements";
        return this.items[this.items.length - 1];
    }

    isEmpty() {
        return this.items.length === 0;
    }
}

How it Works

Think of a Stack like a stack of plates. You can only add a new plate to the top (Push) and remove a plate from the top (Pop).

The last element added is always the first one to be removed. This is known as the LIFO (Last In, First Out) principle.

Advantages

Fast Operations
Adding and removing is very fast (O(1)).

Simple
Easy to implement and understand.

Disadvantages

Limited Access
Can only access the top element.

Fixed Size
If implemented with arrays, size might be fixed.
