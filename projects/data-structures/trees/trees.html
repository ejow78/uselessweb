Binary Search Tree (BST)

A hierarchical data structure where each node has at most two children. In a BST, the left child is smaller, and the right child is greater than the parent.

Search: O(log n) Insert: O(log n) Delete: O(log n)
Ready to start.

class Node {
    constructor(value) {
        this.value = value;
        this.left = null;
        this.right = null;
    }
}

class BST {
    insert(value) {
        const newNode = new Node(value);
        if (!this.root) {
            this.root = newNode;
            return;
        }
        let current = this.root;
        while (true) {
            if (value < current.value) {
                if (!current.left) {
                    current.left = newNode;
                    return;
                }
                current = current.left;
            } else {
                if (!current.right) {
                    current.right = newNode;
                    return;
                }
                current = current.right;
            }
        }
    }
}

How it Works

A Binary Search Tree organizes data so that for every node, elements in the left subtree are smaller, and elements in the right subtree are larger.

This structure allows for very efficient searching, similar to binary search in a sorted array, because at each step you eliminate half of the remaining tree.

Advantages

Fast Search
O(log n) on average.

Sorted Order
In-order traversal gives sorted elements.

Disadvantages

Unbalanced
Can degenerate into a linked list (O(n)) if not balanced.

Complex
More complex to implement than linear structures.
