Queues

A linear data structure which follows a particular order in which the operations are performed. The order is FIFO (First In First Out).

Enqueue: O(1) Dequeue: O(1) Peek: O(1)
Ready to start.

class Queue {
    constructor() {
        this.items = [];
    }

    // Enqueue: O(1)
    enqueue(element) {
        this.items.push(element);
    }

    // Dequeue: O(1) (amortized or with linked list)
    // Array shift is O(n), but conceptually Queue is O(1)
    dequeue() {
        if (this.isEmpty()) return "Underflow";
        return this.items.shift();
    }

    // Peek: O(1)
    front() {
        if (this.isEmpty()) return "No elements";
        return this.items[0];
    }

    isEmpty() {
        return this.items.length === 0;
    }
}

How it Works

Think of a Queue like a line of people waiting for a bus. The first person to arrive (Enqueue) is the first person to get on the bus (Dequeue).

This is known as the FIFO (First In, First Out) principle. Elements are added to the Rear and removed from the Front.

Advantages

Order Preserved
Maintains the order of elements.

Fast Operations
Adding and removing is fast (O(1)).

Disadvantages

Limited Access
Can only access the front element.

Fixed Size
If implemented with static arrays.
