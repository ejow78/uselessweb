Dijkstra's Algorithm

Finds the shortest path from a source node to all other nodes in a weighted graph.

Status: Ready Distance to Target: Infinity 

function dijkstra(graph, src) {
    let dist = new Array(V).fill(Number.MAX_VALUE);
    let visited = new Array(V).fill(false);

    dist[src] = 0;

    for (let count = 0; count < V - 1; count++) {
        let u = minDistance(dist, visited);
        visited[u] = true;

        for (let v = 0; v < V; v++) {
            if (!visited[v] && graph[u][v] !== 0 && 
                dist[u] !== Number.MAX_VALUE &&
                dist[u] + graph[u][v] < dist[v]) {
                dist[v] = dist[u] + graph[u][v];
            }
        }
    }
    return dist;
}

How it Works

Dijkstra's algorithm is a greedy algorithm that finds the shortest path from a single source vertex to all other vertices in a weighted graph. It works by maintaining a set of visited vertices and a set of unvisited vertices. It starts at the source vertex and iteratively selects the unvisited vertex with the smallest tentative distance from the source.

Key Concepts:
* Relaxation: The process of updating the shortest path estimate to a vertex.
* Priority Queue: Often used to efficiently select the vertex with the minimum distance.

Time Complexity

O(V²)
Using a simple array. O(E + V log V) with a Fibonacci heap.

Space Complexity

O(V)
To store distances and visited status.
