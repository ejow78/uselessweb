Max Flow (Ford-Fulkerson)

An algorithm that computes the maximum possible flow in a flow network from a source node to a sink node.

function bfs(rGraph, s, t, parent) {
    // Create a visited array and mark all vertices as not visited
    let visited = new Array(V).fill(false);
    let queue = [];
    queue.push(s);
    visited[s] = true;
    parent[s] = -1;

    while (queue.length !== 0) {
        let u = queue.shift();

        for (let v = 0; v < V; v++) {
            if (visited[v] === false && rGraph[u][v] > 0) {
                if (v === t) {
                    parent[v] = u;
                    return true;
                }
                queue.push(v);
                parent[v] = u;
                visited[v] = true;
            }
        }
    }
    return false;
}

function fordFulkerson(graph, s, t) {
    let u, v;
    let rGraph = new Array(V); // Residual Graph

    for (u = 0; u < V; u++) {
        rGraph[u] = new Array(V);
        for (v = 0; v < V; v++)
             rGraph[u][v] = graph[u][v];
    }

    let parent = new Array(V);
    let max_flow = 0;

    // Augment the flow while there is path from source to sink
    while (bfs(rGraph, s, t, parent)) {
        let path_flow = Number.MAX_VALUE;
        for (v = t; v !== s; v = parent[v]) {
            u = parent[v];
            path_flow = Math.min(path_flow, rGraph[u][v]);
        }

        for (v = t; v !== s; v = parent[v]) {
            u = parent[v];
            rGraph[u][v] -= path_flow;
            rGraph[v][u] += path_flow;
        }

        max_flow += path_flow;
    }
    return max_flow;
}

How it Works

The Ford-Fulkerson method computes the maximum flow in a flow network. It is called a "method" instead of an "algorithm" because it encompasses several implementations with differing running times. The Edmonds-Karp algorithm is a specific implementation of Ford-Fulkerson that uses BFS for finding augmenting paths.

Key Concepts:
* Flow Network: A directed graph where each edge has a capacity and each edge receives a flow.
* Source (s): The node where flow starts.
* Sink (t): The node where flow ends.
* Residual Graph: Indicates additional possible flow. If there is a path from source to sink in the residual graph, it is an augmenting path.

Time Complexity

O(V E²)
For Edmonds-Karp implementation using BFS.

Space Complexity

O(V²)
To store the graph (Adjacency Matrix).
