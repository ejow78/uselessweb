Selection Sort

A simple sorting algorithm that repeatedly finds the minimum element from the unsorted part and puts it at the beginning.

Time: O(n²) Space: O(1) 

function selectionSort(arr) {
    const n = arr.length;
    for (let i = 0; i < n - 1; i++) {
        let minIdx = i;
        for (let j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx]) {
                minIdx = j;
            }
        }
        if (minIdx !== i) {
            [arr[i], arr[minIdx]] = [arr[minIdx], arr[i]];
        }
    }
    return arr;
}

How it Works

Selection Sort divides the input list into two parts: a sorted sublist of items which is built up from left to right at the front (left) of the list and a sublist of the remaining unsorted items that occupy the rest of the list.

The Algorithm:
* Find the minimum element in the unsorted array.
* Swap it with the element at the beginning of the unsorted array.
* Move the boundary between the sorted and unsorted subarrays one element to the right.
* Repeat until the array is sorted.

Mathematical Analysis:
It makes O(n²) comparisons and O(n) swaps. It is inefficient on large lists but has the advantage of making the minimum number of swaps (at most n-1).

Speed (Time Complexity)

O(n²)
Quadratic time complexity makes it inefficient for large datasets.

Memory (Space Complexity)

O(1)
In-place sorting algorithm, requires very little auxiliary memory.
