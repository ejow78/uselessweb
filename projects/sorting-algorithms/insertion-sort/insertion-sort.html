Insertion Sort

Builds the sorted array one item at a time. It picks each new element and inserts it into its correct position in the sorted portion.

Time: O(n²) Space: O(1) 

function insertionSort(arr) {
    const n = arr.length;
    // Iterate from the second element
    for (let i = 1; i < n; i++) {
        // This is the element to insert
        let current = arr[i];
        let j = i - 1;

        // Move elements > current up
        while (j >= 0 && arr[j] > current) {
            arr[j + 1] = arr[j];
            j--;
        }
        // Insert current in its correct spot
        arr[j + 1] = current;
    }
}

How it Works

Insertion Sort builds the final sorted array (or list) one item at a time. It is much less efficient on large lists than more advanced algorithms such as quicksort, heapsort, or merge sort.

The Algorithm:
* Iterate from arr[1] to arr[n] over the array.
* Compare the current element (key) to its predecessor.
* If the key element is smaller than its predecessor, compare it to the elements before. Move the greater elements one position up to make space for the swapped element.

Mathematical Analysis:
In the worst case (reverse sorted array), the algorithm performs n(n-1)/2 comparisons and swaps. This results in a quadratic time complexity:

T(n) = O(n²)

However, in the best case (already sorted array), it only makes n-1 comparisons, resulting in linear time complexity O(n).

Speed (Time Complexity)

Worst: O(n²)
Quadratic growth. Doubling the input quadruples the time.

Best: O(n)
Linear time when the array is nearly sorted.

Memory (Space Complexity)

O(1)
Auxiliary space is constant. It sorts in-place without needing extra memory proportional to the input size.
