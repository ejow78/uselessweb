Shaker Sort

Also known as Cocktail Sort. It's a variation of Bubble Sort that sorts in both directions on each pass through the list.

Time: O(n²) Space: O(1) 

function shakerSort(arr) {
    let swapped = true;
    let start = 0;
    let end = arr.length;

    while (swapped) {
        swapped = false;

        // Forward pass
        for (let i = start; i < end - 1; ++i) {
            if (arr[i] > arr[i + 1]) {
                [arr[i], arr[i + 1]] = [arr[i + 1], arr[i]];
                swapped = true;
            }
        }

        if (!swapped) break;
        swapped = false;
        end--;

        // Backward pass
        for (let i = end - 1; i >= start; i--) {
            if (arr[i] > arr[i + 1]) {
                [arr[i], arr[i + 1]] = [arr[i + 1], arr[i]];
                swapped = true;
            }
        }
        start++;
    }
    return arr;
}

How it Works

Shaker Sort (or Cocktail Shaker Sort) extends Bubble Sort by operating in two directions. While Bubble Sort bubbles items up to the end of the list, Shaker Sort bubbles items up to the end and then bubbles items down to the beginning.

The Algorithm:
* Forward Pass: Iterate from left to right, swapping adjacent elements if they are in the wrong order. The largest element bubbles to the end.
* Backward Pass: Iterate from right to left, swapping adjacent elements if they are in the wrong order. The smallest element bubbles to the beginning.
* Repeat until no swaps are needed.

Mathematical Analysis:
Like Bubble Sort, its average and worst-case complexity is O(n²). However, it can be slightly faster than Bubble Sort for "turtles" (small values near the end of the list) because they move to the beginning much faster.

Speed (Time Complexity)

O(n²)
Quadratic time complexity. Slightly better performance than Bubble Sort in practice.

O(1)
In-place sorting algorithm.
