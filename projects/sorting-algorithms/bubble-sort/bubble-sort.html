Bubble Sort

Repeatedly steps through the list, compares adjacent elements and swaps them if they are in the wrong order.

Time: O(n²) Space: O(1) 

function bubbleSort(arr) {
    const n = arr.length;
    let swapped;

    for (let i = 0; i < n; i++) {
        swapped = false;

        for (let j = 0; j < n - i - 1; j++) {
            // Check if the element is greater than the next
            if (arr[j] > arr[j + 1]) {
                // Swap them
                [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]];
                swapped = true;
            }
        }

        // If no two elements were swapped by inner loop, then break
        if (!swapped) break;
    }
}

How it Works

Bubble Sort is the simplest sorting algorithm that works by repeatedly swapping the adjacent elements if they are in the wrong order.

The Algorithm:
* Traverse from the beginning of the list to the end.
* Compare the current element with the next element.
* If the current element is greater than the next element, swap them.
* Repeat this process for n-1 passes. After each pass, the largest element "bubbles" to the end.

Mathematical Analysis:
The total number of comparisons is the sum of the first n-1 integers:

(n-1) + (n-2) + ... + 1 = n(n-1)/2 ≈ n²/2

This gives us a time complexity of O(n²). Even if the array is sorted, standard Bubble Sort takes O(n²) time, though an optimized version (with a 'swapped' flag) can achieve O(n) in the best case.

Speed (Time Complexity)

Worst: O(n²)
Inefficient for large datasets due to nested loops.

Best: O(n)
Linear time (only with optimization flag) if already sorted.

Memory (Space Complexity)

O(1)
Requires only a single temporary variable for swapping.
