Understanding DNS (Domain Name System)

DNS is the "phonebook" of the Internet. Humans access information online through domain names (like google.com), but web browsers interact through Internet Protocol (IP) addresses (like 142.250.190.46).

The Hierarchy of DNS

1. DNS Resolver (Recursive Resolver)

Usually provided by your ISP. It acts as the middleman between your computer and the DNS infrastructure. It caches results to speed up future queries.

2. Root Nameservers (.)

There are 13 logical root server sets worldwide. They don't know the IP of the website, but they know where to find the TLD servers for .com, .net, etc.

3. TLD Nameservers (Top Level Domain)

These servers manage extensions like .com. They point the resolver to the specific authoritative server for the requested domain.

4. Authoritative Nameservers

The final stop. These servers act as the definitive source of truth for the domain and return the actual IP address (A Record).

Types of DNS Queries

  • Recursive Query: "I need the answer, go find it for me." (Client -> Resolver)
  • Iterative Query: "I don't know, but here is who to ask next." (Resolver -> Root/TLD)
