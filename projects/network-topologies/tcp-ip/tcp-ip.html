Encapsulation Process

As data moves down the stack, each layer adds its own header (and sometimes trailer) to the data from the layer above. This wraps the data like an envelope inside another envelope.

Deep Dive: The TCP/IP Model

The TCP/IP Model (also known as the Internet Protocol Suite) is a concise, 4-layer framework that describes how the Internet functions. Unlike the 7-layer OSI model which is theoretical, TCP/IP is practical.

Layer Breakdown

4. Application Layer

Protocols: HTTP, DNS, FTP, SSH, SMTP.

Creates the data payload (e.g., a requested HTML page or an email). It interfaces directly with software applications.

3. Transport Layer

Protocols: TCP (Reliable), UDP (Fast).

Responsible for end-to-end communication. It breaks large data into smaller chunks called Segments. It adds port numbers to identify which application sent/receives the data.

2. Internet Layer

Protocols: IP (IPv4, IPv6), ICMP, ARP.

Responsible for logical addressing and routing. It wraps the segment into a Packet mainly by adding Source and Destination IP addresses.

1. Network Access Layer (Link Layer)

Protocols: Ethernet, Wi-Fi, MAC.

Responsible for physical transmission. It wraps the packet into a Frame by adding MAC addresses and a Frame Check Sequence (FCS) for error checking.

Encapsulation vs. Decapsulation

  • Encapsulation (Downstream): Happens when you SEND data. Data gets wrapped with headers at each step.
  • Decapsulation (Upstream): Happens when you RECEIVE data. Headers are stripped off layer by layer until raw data remains.
